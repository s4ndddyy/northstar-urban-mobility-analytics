# NorthStar Urban Mobility Analytics

This repository contains the coursework project for the Databases and Analytics module based on the NorthStar Urban Mobility and Logistics case study.

The project analyses operational challenges related to:

* Delivery delays and failures
* Customer complaints
* Route inefficiencies
* Driver and vehicle performance
* Hub and zone level operational issues
* Data architecture limitations
## Objective

The objective of this project is to identify operational inefficiencies within NorthStar and demonstrate how integrated relational and NoSQL analytics can support better operational decision making.

## Project Structure

### 01_data_understanding_and_cleaning.ipynb

Python based data cleaning and preprocessing using:

* Pandas
* Matplotlib
* Seaborn

This notebook includes:

* Data cleaning and standardisation
* Missing value handling
* Feature engineering
* Operational analytics and visualisations

### 02_sql_in_r_analysis.ipynb

SQL within R and R analytics using:

* sqldf
* dplyr
* ggplot2

This notebook includes:

* SQL queries within R
* Aggregation and joins
* Delivery and complaint analysis
* Zone and hub performance analysis
* Visualisations and operational insights

### 03_mongodb_atlas.ipynb

MongoDB Atlas implementation using:

* PyMongo
* MongoDB Atlas

This notebook includes:

* NoSQL document design
* Embedded operational data modelling
* CRUD operations
* Query optimisation and indexing
* Explain plan analysis using IXSCAN

## Datasets

The repository contains:

* Raw operational datasets

* Supporting analytical outputs
